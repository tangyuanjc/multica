# WS-1916 Issue Pulse Aggregation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a read-only `multica issue pulse` contract that computes S1-S5 from Multica truth tables without exposing prompt, webhook, or secret fields.

**Architecture:** A pure Go aggregation package classifies autopilot-origin issue rows and status events; a workspace-scoped handler loads only the required columns and returns `issue-pulse.v1`; the CLI passes an explicit reviewer UUID plus an RFC3339 window. S2 uses a four-way exhaustive partition so `first_pass + reworked + cancelled + in_flight = cohort_total` is mechanically testable.

**Tech Stack:** Go 1.26, Chi, pgx, Cobra, standard-library tests.

---

### Task 1: Pure S1-S5 aggregation

**Files:**
- Create: `server/internal/pulse/pulse.go`
- Test: `server/internal/pulse/pulse_test.go`

- [ ] **Step 1: Write the failing aggregation tests**

Create fixtures for: one first-pass done issue, one rejected then done issue, one cancelled issue, one in-flight issue, one done-then-reopened issue, and one issue with a member comment. Assert the public contract:

```go
got := Aggregate(Input{ReviewerID: reviewer, Since: since, Until: until, Issues: issues, StatusEvents: events, CommentActors: comments, Loops: loops})
if got.S2.FirstPass+got.S2.Reworked+got.S2.Cancelled+got.S2.InFlight != got.S2.Total || !got.S2.ConservationOK {
    t.Fatalf("S2 conservation failed: %#v", got.S2)
}
if got.S2.DoneReopened != 1 { t.Fatalf("done reopened = %d", got.S2.DoneReopened) }
if got.S3.Untouched != 1 { t.Fatalf("untouched = %d", got.S3.Untouched) }
if got.S1.Overall.P50Seconds == nil || got.S1.Overall.P90Seconds == nil { t.Fatal("missing S1 percentiles") }
```

- [ ] **Step 2: Run tests and verify RED**

Run: `cd server && go test ./internal/pulse -run TestAggregate -count=1`

Expected: FAIL because package/types do not exist.

- [ ] **Step 3: Implement the minimal pure aggregator**

Define `Issue`, `StatusEvent`, `CommentActor`, `Loop`, `Input`, and `Response` types. Pair each `to=in_review` event with the next `from=in_review` event; compute nearest-rank P50/P90 over closed intervals. Classify every cohort issue exactly once as `first_pass`, `reworked`, `cancelled`, or `in_flight`; count `done_reopened` separately. Treat an issue as untouched only when creator/assignee/comment/status actors contain no member and the reviewer performed the transition to done. Compute S4 P50 from `created_at` to the last reviewer transition to done. Return S5 rows with only id/title/status/trigger kinds/latest run timestamps and result/consecutive-health fields.

Run: `cd server && go test ./internal/pulse -count=1`
